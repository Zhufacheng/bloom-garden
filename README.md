# 花花草草 · Bloom Garden 🌷

一款輕鬆的養成類小遊戲（PWA 網頁 App）：種花、種草、澆水、收獲，把小花園慢慢擴大。

線上版：<https://Zhufacheng.github.io/bloom-garden/>

## 玩法

1. 在「花店」買種子（開始白送 5 顆青草），種子會進**庫存**，可以一次買很多
2. 點卡片拿起種子，再點空地**連續種植**（不用切工具）
3. 點生長中的植物＝澆水（水乾了會停止生長，出現 💧 提示）
4. 植物成熟發光後，**直接點它＝收獲**，賺取金幣（賣價每天隨市場波動，留意花店行情）
5. 留意隨機事件：蜜蜂來過的花收獲 +50%、彩虹出現時生長加速
6. 用金幣擴充更多土地（3×3 → 5×3），解鎖更大的花園

> 💡 上表的賣價是**基準價**；實際賣價每天隨市場波動 ±25%（花店內有 ▲▼ 行情提示），
> 看好價格高的植物再種比較賺。

- **📈 每日市場**：每株植物的賣價每天固定隨機波動 ±25%，所有裝置一致，0 點刷新
- **🔮 明日行情預告**：花店同時顯示**明天**的價格走勢（▲▼→），
  看好明天漲的花今天先種下去，明天收獲更賺
- **📦 鄰里訂單**：每天 2 張訂單（各指定一種植物、2~4 株），收獲指定植物即計入，
  完成領**基準價 ×1.5** 的賞金（比一般賣價更高），在「任務」面板領取，每天 0 點換新訂單
  - ⚡ **加急訂單**：每天 25% 機率多 1 張加急單（1~2 株、**×2 賞金**）
  - 🎉 **全清獎勵**：同一天把所有訂單都完成，再領 +30 金幣感謝禮
- **📖 植物圖鑑**：頂欄 📖 開啟，記錄 12 種植物的累計收獲次數，收過的會顯示完整花形
  （還沒收過的只顯示種子），集齊 12 種；圖鑑是永久的，**轉生也不會清空**
- **🪴 肥料**：花店 40 金買 1 袋（最多存 5 袋），種植時**自動用掉 1 袋**，
  那株花長速 ×2（地上會顯示 🪴×2 標記），留給貴花最划算
- **🎲 神秘種子**：花店裡 25 金抽 1 顆隨機種子（12 種都有可能）
- **🎰 高級盲盒**：花店裡 50 金抽 1 顆，**保證**是 6 種高級花之一（向日葵～彩虹花）
- **📅 每日簽到**：「任務」面板每天可簽到 1 次，7 天循環（10→15→20→30→40→60→**100** 金幣大禮），
  中斷就從第 1 天重新累積
- **✨ 露珠轉生**（長線 progression）：花店裡「轉生重開」，重置花園換**永久露珠**
  💧（露珠 = ⌊√(累計賺金幣 ÷ 200)⌋，例如賺 800 金幣 = 2 顆），每顆露珠**永久 +5% 賣價**，
  越滾越強；簽到進度會保留
- **💎 露珠商店**：用露珠買**永久升級**（轉生不清空）：
  - 🌱 沃土（💧3）：所有植物生長速度 +10%
  - ⭐ 星光祝福（💧4）：金色植物機率 +5%（可與幸運草疊加到 20%）
  - 💰 金手指（💧5）：所有賣價 +10%
- **🔥 連收 Combo**：15 秒內連續收獲會累積連擊（頂欄顯示 🔥 連收 ×N），
  每第 3 連擊額外 +25% 金幣（最高 +100%），成熟的花多種幾株一起收最賺
- **🎉 隨機事件**（每 1~3 分鐘抽一次，約 70% 機率有事件）：
  - 🐝 蜜蜂造訪：隨機一株成熟植物被標記 🐝，收獲 +50%（金色 + 蜜蜂 = ×3）
  - 🐛 毛毛蟲：隨機一株生長中的植物進度被吃掉 25%（小心！）
  - 🌦️ 快閃雨：所有生長中的植物水分瞬間補滿
  - 💰 黃金時刻：60 秒內所有收獲金幣加倍（趕上連收 Combo 更賺）
  - ⭐ 流星劃過：所有生長中的植物進度立即 +10%（最高推到 99%，差一步成熟）
  - 🌈 彩虹出現：60 秒內所有植物生長加速 30%（花園上方出現 🌈 提示）
- **天氣系統**：每 2~5 分鐘隨機變化
  - ☀️ 晴天：正常流失水分
  - 🔥 炎熱：水分流失加倍，要多澆水
  - 🌧️ 下雨：不用澆水，雨水自動補充水分（花園有下雨動畫）
- **✨ 金色植物**：成熟時 10% 機率變金色（金光閃爍），賣價加倍
- **裝飾品**（一次購買、永久生效，花店內購買）：
  - ⛲ 小噴泉（60）：水分流失變慢 25%
  - 🦋 蝴蝶園（90）：賣出價格 +10%
  - 🐦 鳥屋（150）：每日任務獎勵 +10 金幣
  - 🪵 木柵欄（80）：純裝飾
  - 🚿 自動噴頭（200）：全天候自動補水，炎熱天也不用澆水
  - 🦅 驅蟲稻草人（180）：阻擋毛毛蟲事件
  - 🍀 幸運草（120）：金色植物機率 10% → 15%
  - 🍯 蜜蜂巢（250）：蜜蜂事件標記的收獲加成 +50% → **+75%**
- **🏅 成就**：10 個一次性累計獎勵（累計收獲/賺金幣/最大花園/收集裝飾/圖鑑 6 種/集齊圖鑑/10 連收），在「任務」面板領取

- **每日任務**：每天 3 個隨機任務（收獲/澆水/賺金幣/種植），完成領金幣，每天 0 點刷新；
  面板標題同時顯示**今日戰績**（今天賺了多少金幣、收獲幾株）
- **音效**：種植、澆水、收獲、領獎都有音效（Web Audio 生成，右上角 🔊 可靜音）

進度自動存在手機上（localStorage），離開一段時間再回來，植物也會繼續長大（離線補算最多 8 小時）。

## 在 iPhone 上安裝

1. 用 **Safari** 開啟 <https://Zhufacheng.github.io/bloom-garden/>
2. 點底部的「分享」按鈕 →「加入主畫面」
3. 桌面上就會出現「花花草草」圖示，點開是全畫面 App 體驗，且支援離線

## 本地開發

```bash
npm install
npm run dev      # 開發伺服器
npm run test     # 單元測試（vitest）
npm run build    # 型別檢查 + 建置到 dist/
```

## 技術

React + TypeScript + Vite，原生 CSS（手繪 SVG 植物圖形），localStorage 存檔，
Service Worker 離線快取。

## 部署

目前以「本地建置 → 推送 `gh-pages` 分支」的方式部署到 GitHub Pages：

```bash
npm run build
# 將 dist/ 內容推送到 gh-pages 分支即可
```

`.github/workflows/deploy.yml`（GitHub Actions 自動部署）已備妥，
等 GitHub token 加上 `workflow` scope 後 commit 上去即可啟用。
